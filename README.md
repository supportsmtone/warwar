# 우당탕탕요절복통 송년회·자체대회 웹 대진표 (2026-11-14)

- 주소: https://playjc.co.kr/
- 한 파일(`index.html`)로 동작하는 정적 웹입니다. 서버·외부 CDN 없이 오프라인(`file://`)에서도 열립니다.
- 흐름: 참가자 입력 → 전반전 조 추첨(5개조, 다시 뽑기·확정) → 조별 복식 로테이션 경기·점수 → 순위 → 후반전 조 배치 → 후반전 → 급수 발표·시상.
- 참가자 명단과 점수는 **운영자 브라우저(localStorage)에만** 저장됩니다. 이 저장소에는 회원 실명·연락처·나이가 없습니다.
- 테스트: `node --test test/draw_core.test.js test/bracket_core.test.js`
